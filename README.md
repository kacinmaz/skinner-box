# Skinner Box — Prototype

## Starten

1. Entpacke den Ordner.
2. Öffne `index.html` in Chrome, Firefox, Edge oder Safari.
3. Klicke auf **New Run**.

Es wird kein Server benötigt.

## Enthalten

- Title Screen
- 25 Multiple-Response-Fragen aus der Probeklausur 2025
- Klickbare rechteckige Antwortfelder
- Mehrfachauswahl
- Submit / Continue
- zufällige Fragenreihenfolge pro Run
- End Screen

## Wichtig

Die hochgeladene Probeklausur enthält keinen Antwortschlüssel.
Deshalb bewertet dieser Prototyp Antworten noch nicht als richtig/falsch.
Sobald ein Antwortschlüssel vorliegt, kann `questions.js` um die korrekten
Antwortindizes ergänzt und die Auswertung in `app.js` aktiviert werden.
